# daru 2.7 — 완료 안내와 복호화 옵션 설명 개선

Xcode 27.1 / iOS 27.1 SDK · iPhone ARM64 · SideStore 서명 설치용

## v2.7 문구 개선

- **내보내기 완료 알림:** “작업 완료 — 복호화된 IPA를 내보냈습니다. daru가 시작 화면으로 돌아왔습니다. 새 IPA를 선택해 다음 작업을 시작할 수 있습니다.”
- **복호화 옵션 이름:** “복호화 호환 모드 (실험)”
- **옵션 설명:** “일반 복호화로 앱이 실행되지 않을 때 켜보세요. 일부 작은 구성 파일도 추가로 처리합니다. 결과에 EXPERIMENTAL이 표시될 수 있으며, 앱 실행 여부는 직접 확인해야 합니다.”
- **EXPERIMENTAL 완료 안내:** 간단히 IPA가 준비되었다는 사실과 LiveContainer에서 실행을 확인하라는 메시지만 표시합니다.
- 기능, 파일명, Liquid Glass 화면, 앱 아이콘, 화면 초기화 동작은 **v2.6과 동일**합니다.

## 기존 기능 (v2.6부터)

1. **① IPA 선택 취소 / 다시 선택:** 파일을 등록한 뒤 **선택 취소**를 눌러 선택을 해제할 수 있습니다. 원본 파일은 삭제하지 않습니다. daru 폴더의 다른 IPA를 다시 선택하면 됩니다.
2. **② IPA 생성 → ③ 내보내기 파일 이름:** 이전의 `FairPlayed-target-unsigned.ipa` 대신 **`daru_재설치.ipa`**로 생성됩니다. SideStore로 이 파일을 서명·설치해 ④ 복호화를 진행합니다.
3. **④ EXPERIMENTAL 결과 생성 성공 안내:** 현재 설치에서 실제 복호화 작업이 끝나고 `-EXPERIMENTAL.ipa`가 생성된 경우에만 **“복호화 성공 · EXPERIMENTAL”** 알림을 표시합니다. 사용자가 LiveContainer에서 동작을 확인한 형식이지만, 모든 앱에 대한 복호화 완전성 보장은 아닙니다.
4. **⑤ 결과 내보내기 후 자동 초기화:** 복호화 IPA를 파일 앱 등에 **공유 완료했을 때만** daru는 패키징 첫 화면으로 돌아가고 복호화 탭에 **“내장된 앱이 없습니다. 새 IPA를 선택해 주세요.”**를 표시합니다. 공유를 취소하면 초기화하지 않습니다.

### 초기화 범위에 관한 중요한 설명

**이것은 순정 daru처럼 '보이게 하는 화면 상태 초기화'입니다.** SideStore로 설치한 서명된 앱 번들의 `EmbeddedPayload`는 실제로 남아 있습니다. iOS는 일반 앱이 설치된 자기 코드 번들을 삭제·변경하는 것을 허용하지 않습니다.

daru는 설치된 현재 번들의 경로에 화면 초기화 표시를 저장합니다. **새로운 대상을 패키징해 SideStore로 다시 설치하면** 새로운 앱 번들을 감지하여 정상적인 대상 앱 상태를 표시합니다.

초기화 과정에서는 **복호화된 IPA 파일과 사용자가 파일 앱에 복사한 원본 IPA를 삭제하지 않습니다.** 다만 daru가 생성한 임시 서명용 IPA 등은 정리하며 선택 상태만 해제합니다. 로그는 진단 목적상 유지됩니다.

## 사용 순서

1. 파일 앱에서 `나의 iPhone → daru` 폴더에 IPA 복사
2. **패키징 → IPA 선택 (daru 파일 목록)**에서 파일 지정
3. 선택 변경이 필요하면 **선택 취소** 후 다른 파일 선택
4. **② 서명용 IPA 만들기** → **③ daru_재설치.ipa 내보내기**
5. SideStore에서 `daru_재설치.ipa` 서명해 홈 화면에 설치
6. **복호화 → ④ 복호화 실행**, 필요하면 복호화 호환 모드 (실험) 사용
7. **EXPERIMENTAL** 결과가 나오면 성공 알림을 확인하고 **⑤ 복호화 결과 IPA 내보내기**
8. 파일 공유가 정상 완료되면 daru가 **패키징 첫 화면으로 자동 복귀**, 복호화 탭에는 **내장된 앱이 없습니다** 표시

**실제 iOS 27.2.1 기기에서의 안정성은 사용자 테스트가 필요합니다.**
